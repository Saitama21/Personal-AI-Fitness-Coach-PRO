# CNC Trainer MVP

Учебный браузерный симулятор под логику ShopTurn / Sinumerik 828D.

## Запуск
Откройте `index.html` двойным кликом в браузере.

## Что уже работает
- токарная сцена: патрон справа, заготовка слева;
- оси X/Z и перемещение инструмента;
- рабочий и безопасный ход;
- простое снятие материала;
- сверление;
- базовый режим фрезерования X/Y/Z;
- револьвер на 15 инструментов;
- учебное задание и журнал действий;
- адаптация под мобильный экран.
