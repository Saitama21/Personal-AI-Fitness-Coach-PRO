# FORMA AI Mobile v0.1.0

Мобильный PWA-клиент персонального фитнес-тренера. Интерфейс спроектирован прежде всего под iPhone 14 / 15 / 16 / 17, включая Pro Max: портретная ориентация, safe-area для Dynamic Island и Home Indicator, нижняя навигация под большой палец, матовый Liquid Glass и пастельная палитра.

## Что уже работает

- Первичная анкета: имя, возраст, рост, вес, цель, уровень, расписание и оборудование.
- Генерация адаптивного плана на 4 недели.
- Экран тренировки с весом, повторениями, отметкой подходов, RPE и болью.
- Анализ завершённой тренировки с оценкой сна, энергии и настроения; приложение автоматически меняет следующие рабочие веса: увеличить, оставить, снизить или заменить.
- Карточки упражнений с пошаговой техникой, ошибками и SVG-фотоинструкцией «старт → движение».
- Прогресс, история и локальное сохранение данных.
- Чат тренера: локальный режим работает без ключа; реальный AI включается одной переменной Railway.
- PWA: установка на домашний экран iPhone и базовая офлайн-оболочка.

## Быстрый запуск локально

Требуется Node.js 20+.

```bash
npm start
```

Открыть: `http://localhost:3000`

Проверка:

```bash
npm test
npm run check
```

## Загрузка через GitHub Desktop → Railway

1. Распакуй архив в отдельную папку.
2. В GitHub Desktop выбери **File → Add Local Repository** или **Create a New Repository**.
3. Добавь все файлы, сделай commit и нажми **Publish repository** / **Push origin**.
4. В Railway создай **New Project → Deploy from GitHub repo** и выбери репозиторий.
5. Railway обнаружит `Dockerfile` автоматически.
6. В сервисе открой **Settings → Networking → Generate Domain**.
7. Проверка здоровья уже задана в `railway.toml`: `/health`.

Сервер слушает `0.0.0.0` и переменную `PORT`, которую Railway назначает автоматически.

## Подключение настоящего ИИ

В Railway открой **Service → Variables** и добавь:

```env
OPENAI_API_KEY=твой_секретный_ключ
OPENAI_MODEL=gpt-5-mini
APP_NAME=FORMA AI
```

Ключ используется только сервером в `src/ai.js` и не передаётся в браузер. Если ключ отсутствует или API временно недоступен, приложение автоматически использует локальный безопасный алгоритм.

## API

- `GET /health` — healthcheck Railway.
- `GET /api/config` — режим приложения и AI-статус.
- `GET /api/exercises` — библиотека упражнений.
- `POST /api/plan/generate` — генерация плана.
- `POST /api/workout/analyze` — анализ тренировки.
- `POST /api/coach` — ответ AI-тренера.

## Структура

```text
public/              мобильный интерфейс и PWA
src/exercises.js     библиотека упражнений
src/plan-engine.js   генератор плана и прогрессия
src/ai.js            защищённый серверный AI-слой
server.js            Node HTTP-сервер и API
railway.toml         Railway healthcheck/restart
Dockerfile           воспроизводимая сборка
```

## Безопасность

Приложение не ставит диагнозы. Боль 5/10 и выше переключает анализ на снижение/замену нагрузки. При острой, нарастающей или необычной боли, онемении, головокружении или затруднённом дыхании пользователь получает рекомендацию прекратить тренировку и обратиться за медицинской оценкой.
