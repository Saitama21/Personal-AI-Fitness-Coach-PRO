# FORMA AI v0.2.0

Mobile-first PWA персонального фитнес-тренера. Основной runtime находится в `public/`, сервер и API — в `server.js` и `src/`.

## Что реализовано
- премиальный iOS-oriented интерфейс с контрастной спортивной палитрой и нижним dock;
- персональный цикл на 8 недель;
- смена вариаций упражнений каждые 2 недели при сохранении двигательных паттернов;
- разные акценты нижней части тела: «Ноги + выносливость» и «Ягодицы + объём»;
- автоматическое создание нового 8-недельного цикла после завершения текущего;
- журнал подходов, веса, повторений, RPE и боли;
- динамическое добавление сетов во время тренировки;
- экран техники с пошаговыми подсказками, работающими мышцами и безопасной заменой;
- адаптация последующих весов по фактическому выполнению и восстановлению;
- локальное хранение прогресса;
- PWA Service Worker и offline app shell;
- Railway-ready Node.js сервер.

## Запуск
```bash
npm start
```
Открыть `http://localhost:3000`.

## Проверка
```bash
npm run check
npm test
```

## Переменные окружения
Без `OPENAI_API_KEY` приложение работает в локальном режиме. При наличии ключа сервер включает AI coach через настройки из `src/ai.js`.
